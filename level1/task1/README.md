# Simple Static Website

## About
This is a simple multi-page static website built as part of the Codveda Web Development Internship – Level 1, Task 1. It is a personal/portfolio website for Swati Singh, a BCA student and aspiring full-stack web developer.

## Features
- Multi-page website (Home, About, Contact)
- Responsive layout using CSS media queries
- Navigation bar on every page
- Hero section with introduction
- About section with education and skills
- Contact form with basic HTML validation
- Consistent footer on all pages

## Technologies
- HTML5
- CSS3

## Pages
- **Home** – Introduction, highlights
- **About** – About me, education, skills
- **Contact** – Contact form and contact details

## Folder Structure
```
codveda-level1-task1-static-website/
├── index.html
├── about.html
├── contact.html
├── css/
│   └── style.css
├── assets/
│   └── images/

```

## How to Run
Just open `index.html` in any web browser. No server or installation needed.
