# Swati Singh – Portfolio

## About
This is a single-page personal portfolio website built as part of the Codveda Web Development Internship – Level 1, Task 2. It showcases my skills, projects, and education as a fresher full-stack web developer.

## Features
- Responsive single-page layout
- Sticky navigation with smooth scrolling
- Hero section with introduction
- About Me section
- Skills section with categorized tags
- Projects section with project cards
- Education timeline
- Contact section with form and contact details
- Simple animations (fade-in, hover effects)
- Mobile-friendly hamburger menu

## Technologies

- JavaScript (Vanilla)
