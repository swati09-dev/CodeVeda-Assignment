# Responsive Developer Showcase

## About
A responsive single-page website built as part of the Codveda Web Development Internship – Level 2, Task 1. The main goal of this project is to demonstrate responsive web design using CSS Flexbox, CSS Grid and media queries.

## Objective
This project demonstrates responsive web design using CSS Flexbox, CSS Grid and media queries.

## Features
- Responsive navbar with mobile toggle
- Flexbox-based hero section (text + image side by side)
- Flexbox-based about section with stat boxes
- Flexbox-based skills section with tag groups
- Grid-based project showcase (3 cols → 2 cols → 1 col)
- Flexbox-based contact section
- Flexbox footer
- Mobile, tablet and desktop support
- Smooth scroll navigation

## Where Flexbox is Used
- Navbar (logo left, links right)
- Hero section (text left, image right)
- About section (text + stats side by side)
- Skills section (groups wrap into rows)
- Contact section (form + info side by side)
- Footer (text + links)

## Where CSS Grid is Used
- Projects section (3-column grid that adapts to 2 and 1 column)

## Technologies
- HTML5
- CSS3
- JavaScript (mobile nav toggle + form feedback only)

## Responsive Breakpoints
- Desktop: 1024px and above
- Tablet: 768px – 1024px
- Mobile: below 768px
